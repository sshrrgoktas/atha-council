# Atha Council · OpenCode Görev Ajanı

Yalnız Konseyin sahibi tarafından onaylanmış Görevler kayıtlarını çalıştırır. Sohbet katılımcısı olarak çalışmaz. Ayrı yerel çalışma kopyası kullanır, otomatik push/merge/yayın yapmaz. Yerel özel anahtar yalnız PC'de kalır.

Mevcut yerel işçinin yapılandırmasını veya çalışan tüneli değiştirmeden önce cihaz üzerindeki kurulum ve yetkiler doğrulanmalıdır.
